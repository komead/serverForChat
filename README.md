Сервер общается с клиентами по протоколу TCP. Сесвер обрабатывает следующие сообщения:
- Запрос на регистрацию;
- Запрос на вход;
- Отправка общедоступных и личных сообщений;
- Также сервер рассылает пользователям список всех пользователей в сети (правильнее было бы отправлять только тех, кто вошёл и вышел).

Сообщение представляет из себя json и обязательно содержит ключ кода операции (остальные ключи меняются в зависимости от кода операции). Коды операций находятся в OperationCode. 
Правильнее было бы парсить json в какой-нибудь класс, но я делал это в Map.
Использовал библеотеку от Google.

К БД MySQL подключался с использованием jdbc. Подключение находится в классе DatabaseManager.
Также для создания структуры при запуске и её обновлении использовались миграционные файлы. В базе данных хранятся только пользователи. Пароли не шифровал.
Миграционные файлы с SQL запросами находятся в resourses\db\migration.
